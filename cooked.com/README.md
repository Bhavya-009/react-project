# 🍽️ Cooked.com

A modern React + Vite recipe discovery web app that helps users search and explore recipes with smart filters like cooking time, calories, and dietary preferences.

Built with a clean UI, and Spoonacular API integration.

---

## 🌟 Features

- Search recipes by name
- Veg / Non-Veg filtering
- Filter by cooking time, calories
- Recipe cards with images
- Responsive modern UI
- Dark themed interface

---

## 🛠 Tech Stack

- React
- Vite
- Tailwind CSS
- JavaScript
- Spoonacular API
